# 本地路由规则

第三阶段加入的本地规则是 Weave 的轻量 P1 分流能力。规则保存在应用的 `noBackupFilesDir`，使用 Android Keystore AES-GCM 加密；输入不会上传，也不会因为编辑规则触发远程规则集请求。

支持五种类型：完整域名、域名后缀、域名关键词、IPv4 CIDR、IPv6 CIDR。动作支持跟随默认出口、直连和阻止。匹配顺序为列表顺序，但应用分流始终在本地规则之前。

Mihomo 编译顺序为：应用 UID/进程规则 → 离线策略包 → 本地规则 → 国内智能直连 → 默认出口。国内直连开启时，DNS 会让 `geosite:cn` 返回真实地址，避免 GEOIP 看到 fake-IP；应用规则仍然优先。Route Lens 只做确定性本地模拟，不宣称远端观测结果。

远程 rule-provider、签名规则集和后台定时更新不在本阶段开启，避免引入隐式网络请求和常驻耗电。
