# 本地开源发行配置

> 这是一份工程边界和发布清单，不是法律意见，也不保证某个版本在任何地区都不受监管。
> 发行者仍应根据实际分发方式、用户群体、节点来源和运营行为咨询熟悉当地法规的专业人士。

## 这份配置承诺什么

本仓库的公开预览构建按 `local-open-source` 发行配置维护：

- Weave 是运行在用户设备上的客户端软件，不运营账号系统、云端控制面、代理中继、节点市场或订阅服务；
- 不内置节点地址、订阅凭据、用户账号、广告、统计、崩溃上报或流量日志服务；
- 不包含应用远程更新器、远程配置中心或“失联后切换”的隐藏控制通道；GitHub Release 是人工发布的静态源码和构建产物；
- 连接、订阅刷新、DNS、IP 质量检测和局域网互传都由用户在本机主动触发或配置；
- 运行配置、订阅内容、应用分流、DNS 选择和诊断结果默认留在本机，敏感文件不参与 Android 备份；
- 发行包应与对应源码、内核来源、补丁、依赖许可、SBOM、校验和及构建说明一起提供。

“本地”指 Weave 不提供集中式后台服务，不表示网络请求永远不会离开设备。用户主动导入的 HTTPS 订阅、选择的代理节点、DoH/DoT 解析器、IP 质量检测端点和同一局域网设备仍会收到其完成请求所必需的网络数据；清单见 [`NETWORK_ENDPOINT_INVENTORY.md`](NETWORK_ENDPOINT_INVENTORY.md)。

## 明确不做的事情

发行版不得把客户端包装成代理/VPN 接入服务，不得代用户提供节点、跨境通信线路、账号代办、流量转发、集中式规则下发或网络控制台。README、截图、Release 文案和 issue 回复也不得暗示 Weave 能规避监管、保证匿名、保证“零日志”或保证任何节点/地区一定可用。

用户选择的订阅、节点和目标网站由其各自运营者负责；Weave 不为这些第三方的内容、可用性或合规性背书。应用只提供本地配置和本地路由能力，用户仍应遵守适用的法律、平台规则、网络使用政策和订阅服务条款。

## 发布前必须复核

1. 从干净 checkout 构建，确认没有未审查的后端地址、遥测 SDK、远程更新器、动态代码加载、默认节点或真实凭据。
2. 运行 `bash tools/audit-local-release.sh`，并人工检查脚本输出的网络端点、Android 权限、第三方库和内核构建来源。
3. 对准确的 commit 生成 Android ABI 包、SHA-256、R8 mapping、native symbols、SBOM、许可证清单和构建日志；不要把 universal APK 当成移动发行包。
4. 在发行说明中标明这是 alpha/预览软件、已知限制、支持版本、数据路径和不提供托管服务；不发布真实订阅链接、节点凭据、二维码、私钥或未脱敏日志。
5. 开启 GitHub 私密漏洞报告，并对 issue、讨论区和拉取请求模板保留敏感信息脱敏提示。
6. 如果发行者在中国大陆分发、运营、提供配套服务或处理用户数据，应在上线前按具体事实做合规评估。免费、非营利、开源和没有云服务器本身都不是自动豁免条件。
