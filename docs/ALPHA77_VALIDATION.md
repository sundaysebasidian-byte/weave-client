# alpha77：订阅详情滚动修复

- 原布局：不可滚动的表单 Column 下嵌一个最大 260dp 的节点 LazyColumn。表单、审计和质量矩阵增高时，节点区域可能被挤小/裁切，外层内容也无法滑动。
- 新布局：使用单一有界 LazyColumn，详情作为头部 item，节点使用稳定 key 和独立懒加载 item；不再嵌套节点滚动窗口。内容最大高度 560dp，同时受弹窗实际可用高度约束。
- 保留原标题、底部关闭/删除按钮、文案、颜色和行样式；不修改内核、订阅载荷或分流数据。
- 增加 `SubscriptionDetailScrollTest`：大字体、200 个节点、8 行质量矩阵下检查只有一个可按索引滚动的列表，能到末节点、返回表单、搜索空结果，底部按钮保持可见。使用合成数据，无网络/私人订阅读取。
- 本轮 ADB 未发现设备；不声称完成真机滑动体验验证。UI 回归测试只编译，待设备可用时运行。
