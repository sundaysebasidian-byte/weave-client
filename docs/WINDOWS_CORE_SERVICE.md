# Windows 核心服务迁移

状态：服务协议、会话后端、客户端连接层、SCM 宿主及 WinUI 调用路径已加入。TUN 不再提升整个 GUI；必须连接受保护的已安装服务，便携版与旧每用户安装缺少服务时明确拒绝。连接就绪和停止归属修复后，原生 180 项核心用例、WinUI 与普通账户服务验收通过。机器级安装器已加入独立版本和服务恢复流程，当前安装事务验收仍在运行，不能视为正式发行。

## 已实现的边界

- `BrokerProfile` 只携带本次使用的 provider、节点标识、应用规则和固定设置；不含订阅来源、展示名、任意配置/核心/geodata 路径。服务强制生成 TUN 配置，重新核验节点和规则；DNS 不允许文件、用户信息或选择接口的 fragment。
- `BrokerRuntimeInfo` 只返回代理端口、IPv6 设置和 provider 数量，不返回核心控制密钥、控制端口或会话文件路径。测速、流量和 DNS 只能通过对应命令；测速 URL 固定，节点须属于当前会话。
- 消息采用有版本的长度帧，单帧 40 MiB；拒绝重复/未知字段、未知操作、缺失或非法 null 参数。已开始的帧 30 秒超时，已认证空闲连接不会被当作传输超时。每连接最多四个未完成请求。
- `BrokerWindowsPipe` 使用首次实例与精确客户端访问权限，拒绝网络/匿名身份。客户端以 Identification 打开本机管道，发送任何连接数据前核对 SCM 报告的服务 PID 和进程映像；服务读取固定握手后核对 OS 客户端 SID、PID、会话与指定 GUI 映像。安装目录保护仍须由服务宿主完成。
- `BrokerSession` 持有私有会话、核心和控制器；连接 EOF、停止请求或服务停止会撤销在途启动并清理本会话。校验探针测试实际启动一个无网络子进程，证明 EOF/停止会终止它；清理失败保留文件及状态。
- `BrokerClient` 按请求 ID 分派并发返回，最多三个普通请求在途，为停止保留一个名额；取消测速只停止调用方等待，仍排空迟到的返回。取消启动撤销整条连接；未知返回/坏帧/服务退出使未完成操作失败并通知断开。重复停止合并，停止确认必须在核心退出后返回。配置校验取消现在等待子进程退出；未确认退出时保留进程句柄及会话。
- Windows YAML 在别名展开时累计 UTF-8 标量预算，在输出时限制缓冲区和最终字节数，避免小输入通过别名或转义绕过 5 MiB provider 上限。
- `Weave.Core.Service` 在任何核心启动前把自身加入关闭即终止子进程的 Job。宿主检查 Program Files 下的安装树、所有祖先的替换权限、所有者和重解析点，核验固定 Windows x64 核心及 geodata 哈希；ProgramData 私有目录携带 ACL 原子创建，未知弱权限旧目录拒绝使用。固定管道句柄在断开后复用，避免每次重建实例留下名称抢占间隙。
- SCM 停止取消会话并等待清理；15 秒不能完成则结束服务进程，由 Job 回收子进程。服务仅接收已安装 GUI 映像的客户端。仅可丢弃 Windows CI 会安装测试服务并以新建普通用户运行合成探针，验证本地 TUN 转发、错误映像拒绝、断开重连和服务崩溃回收；该路径不在开发者主机自动运行。测试配置只保留 ChangeNotify/LoadDriver 权限，是否足够以原生验收为准。服务仅在自身进程 DACL 增加 Authenticated Users 的 QUERY_LIMITED_INFORMATION，保留原有权限；让普通客户端核验映像，不增加终止、内存读写或句柄复制权限。合成探针同时检查这些操作仍被拒绝。

管道策略依据 [Windows 管道访问权限](https://learn.microsoft.com/en-us/windows/win32/ipc/named-pipe-security-and-access-rights)、[客户端身份与模拟级别](https://learn.microsoft.com/en-us/windows/win32/ipc/impersonating-a-named-pipe-client) 和 [OS 客户端 PID 查询](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getnamedpipeclientprocessid)。客户端没有创建同名服务端实例的权限；首次实例检查仍不能代替 SCM 身份核验。

## 完整接入前必须完成

1. 服务宿主只从管理员保护的安装目录加载固定核心及依赖；验证路径、ACL、重解析点和核心哈希。ProgramData 会话根目录原子创建私有 ACL，未知/弱权限旧目录拒绝使用。
2. SCM 生命周期、受限服务权限与服务崩溃时子进程退出。核心启动前即建立进程生命周期约束，不能只在子进程启动后补 Job。
3. 普通权限 GUI 接入：连接、取消、断开、流量、测速、订阅 DNS 和异常退出；系统代理仍由用户进程按归属恢复。服务不可用不能回退为提升整个 GUI。
4. 安装/升级/卸载事务：受保护的机器级二进制、现有每用户数据保留、服务停止确认、失败恢复。不同管理员凭据授权不得切换用户配置。
5. 原生 Windows 上验证标准用户访问、假管道/错误映像拒绝、其他用户不能控制现有会话、GUI/服务进程退出、真实 TUN 转发和卸载恢复。

组件本地测试使用 macOS 回环或合成数据，不接管主机网络。Windows 专属身份测试在其他系统明确跳过。`Weave.BrokerProbe` 仅为测试进程，未包含在产品发布目录。

## 当前 WinUI 路径

- TUN 连接、取消、停止、流量、节点测速和订阅 DNS 经认证服务连接；服务握手前核验安装树，GUI 不持有服务控制器密钥。系统代理模式仍启动当前用户的本地核心。
- 界面仅持有端口/TUN/provider 数量的 `ConnectionEndpoint`，保留对象身份和网络版本的过期结果检查；诊断与隐私浏览器使用该端口。
- HKCU 系统代理与 DPAPI 订阅均留在当前用户；服务异常退出触发代理恢复。无服务时显示 W-S01；不回退为提升整个 GUI。
- 本地模型编译零警告，166 项核心回归通过、5 项原生 Windows 用例跳过；实际 WinUI 构建和普通用户服务验收由对应 CI 另行确认。安装、升级、卸载和旧版迁移尚未交付。

## 机器级安装事务（验收中）

- 安装需要管理员授权，固定使用系统已知的 64 位 Program Files 下 `Weave`。旧每用户安装目录不复用，不运行 HKCU 指向的旧卸载程序；用户配置继续由原用户的 GUI 读取，安装器不读取、解密或迁移 DPAPI 数据。
- Native C++ 边界由现有 Visual Studio 工具链静态链接，仅依赖系统库；Inno 在受保护的临时目录解包它。执行服务前检查安装树及祖先的所有者、ACL、目录链接；不修复可写的未知旧目录。依据 [Inno 临时目录与 DLL 加载保护](https://jrsoftware.org/is6help/topic_securitymeasures.htm)。
- 每次安装使用 `versions/<构建提交>-<本次标识>` 新目录。写入并 flush 恢复记录后，停止并等待旧服务实际退出；旧版本全部保留，不在原位覆盖核心依赖。新服务仅授予 ChangeNotify/LoadDriver 权限，普通用户只有服务配置/状态查询权。
- 安装与卸载在初始化时原子获取同一个跨会话 mutex，贯穿文件和服务操作；已存在或无法取得时拒绝继续。隔离验收同时覆盖并发安装和卸载拒绝。
- 新版本复制完成且界面关闭后切换 SCM 路径，确认新服务启动。安装前持久保存原桌面/开始菜单快捷方式，失败恢复原服务和快捷方式字节；未知归属的入口拒绝覆盖。Inno 的安装后异常不会自动造成失败退出，因此显式以事务提交状态返回退出码，并阻止失败版本启动。失败版本文件与恢复证据保留。
- 未提交的 v2 恢复记录在下一次安装时先恢复；损坏或归属不符时保留记录并拒绝继续。完整断电、安装器强杀、损坏记录人工恢复仍需进一步验收。
- 卸载先要求本安装树的 GUI 退出，核对当前服务映像、账户和类型，再停止、确认退出并删除服务。失败在删除产品文件前中止。Inno 只处理自身安装记录，保留未知文件、用户 LocalAppData、服务 ProgramData 和历史恢复记录。依据 [卸载阶段事件](https://jrsoftware.org/is6help/topic_scriptevents.htm)。
- 隔离 CI 覆盖可写目录和目录链接拒绝、全新安装、普通账户 GUI 启动、升级保留旧版本逐文件哈希、故意损坏新服务后的恢复、外来服务路径拒绝，以及卸载保留用户和未知文件。执行结果以对应提交产物为准；未完成的测试不记为通过。

此阶段尚不包含签名、跨管理员凭据的交互式 UAC 验收、旧每用户快捷方式清理、旧版本自动淘汰或真实设备上的升级/断电耐久。旧版本保留为恢复输入，未据版本号或同名判断其可删。
