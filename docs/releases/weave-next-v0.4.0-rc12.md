# Weave Next 0.4.0-rc12 · Build 118

Android ARM64 生产签名预发布版。本版汇总 RC11 后进入主线的 Android 改动。

## 网络工具

- Weave Share 支持 HTTP／SOCKS5 混合接入、地址识别、二维码配对和活动连接拓扑。临时授权支持独立凭据、双向限速、到期断开和单设备出口。可选用已有的故障切换组作为共享设备的出口池。
- 可将共享限定在一个明确选定的 Wi‑Fi 接入点。离开该接入点时停止监听并关闭活动连接，返回相同接入点且 Android 提供完整网络身份时恢复。接入点信息在设备加密存储。系统 HTTP 代理继续监听本机环回地址。
- Weave Chain 支持跨订阅编排多跳、添加与拖动节点、入口备援和按应用分流。显示单跳及整链检测，可重测入口并让备援组重新选择。推荐结果基于当前已加载链路的两次实测，网络路径改变后清除。
- DNS 支持 DoH、DoT、DoQ、自定义上游和 Fake-IP。诊断页面显示实际经过的上游、协议、响应、耗时和故障切换。三个至六个加密自定义上游组成的解析池可按本次网络的表现调整并发数。

## 使用体验与稳定性

- 更新 Android 多语言和窄屏布局，涵盖设置入口、语言切换及定时更新选项。
- 修正共享设备在手机直连模式下忽略已指定出口的问题。共享流量和撤销按设备授权区分，HTTP 持久连接逐请求验证凭据。
- 内核配置载入停止输出原始 DNS 设置。共享视图只读取活动共享连接，四个 Android ABI 的原生内核从锁定源码重建。

## 性能实测

| 执行路径与负载 | 优化前 | 优化后 |
| --- | ---: | ---: |
| DNS 调度，6个加密上游的稳态请求数 | 6.00 次/查询 | 2.50 次/查询 |
| 代理链列表，10,000 个候选节点、8 个引用 | 1,082 μs | 208 μs |
| 共享拓扑，为 1,000 条连接排序 | 294 μs | 99 μs |
| 断开共享设备，1,000 条模拟连接 | 430 μs | 58 μs |
| 分配单个 32 KiB 限速窗口 | 387 ns，512 B 分配 | 48 ns，零分配 |
| 路由规划，2,048 条规则 | 23.37 μs | 19.09 μs |
| 生成 512 × 512 二维码的临时像素数组 | 1 MiB | 32 KiB |
| 仅选中一个固定节点时导入内核的节点数 | 3 | 1 |
| 共享快照，5,000 条普通连接及 20 条共享连接 | 7.92 ms | 0.068 ms |
| 代理链编辑器，10,000 个候选节点、8 个可见节点 | 1.932 ms | 0.587 ms |

耗时取三轮中位数。DNS 压测的模拟查询耗时为 1.191 → 1.207 ms，收益主要来自减少上游请求和分配。数据衡量对应执行路径。
