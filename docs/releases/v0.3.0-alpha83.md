# Weave Android 0.3.0-alpha83

更从容的交互，更清楚的网络状态。

![八种主题配色示意，非实机截图](https://raw.githubusercontent.com/sundaysebasidian-byte/weave-client/v0.3.0-alpha83/docs/images/themes.png)

八种主题与 Liquid Glass 风格层次、图形化应用分流、本地加密订阅、兼容客户端配置导入与可选订阅分享，继续保留。

## 本次更新

- **操作更稳**：检测卡片固定位置，结果逐项更新；滚动或进入后台时暂停首页统计，策略包读写移到后台线程。
- **诊断更明确**：统一网络与隐私入口，区分 DNS、TLS、超时、重定向与服务响应；取消或切换网络后不会把旧结果当成当前证据。
- **反馈更安全**：新增脱敏检测摘要，先预览再手动复制，不包含实际 IP、节点名称、订阅凭据或浏览器指纹。
- **恢复与兼容改进**：汇总 alpha78–83 的网络变化恢复、订阅更新预览、失效出口处理和 WebView 渲染恢复改进；补齐新增提示的六语言翻译。

- 本地 229 项 JVM 测试、3 项检测界面回归通过；lint 无错误（仍有警告）。
- 这份 APK 已在 vivo 手机上从 alpha80 保留数据覆盖安装至 alpha83；不代表所有机型、长时间连接、耗电或高刷新率测试已完成。
