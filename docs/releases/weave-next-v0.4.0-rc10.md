# Weave Next 0.4.0-rc10 · Build 116

Android ARM64 生产签名预发布版。汇总了 RC8 和 RC9 的优化，并加入新首页、连接动效和全局过渡动画。使用与已签名 RC7 相同的证书，支持覆盖安装。曾自行签名安装开发包的用户，如遇签名冲突，请先在当前应用中导出备份，再卸载并安装本版。

## 界面与动效

- 首页用编织动效连接状态与底部控件。连接时光波从主按钮扩散，丝线收紧成结，连通后随流量变化。持续动效仅在页面显示时运行，并遵守系统动画设置。
- 统一按钮触点、弹簧反馈、开关、滚动数字与浮动提示。系统栏图标随应用配色调整，主按钮的双击保护使用界面时钟。
- 工具页从点按位置展开为卡片，返回时收回，支持预测性返回过渡。弹窗从触点展开。设置、分流和订阅滚动后显示紧凑标题。列表入场效应只在停稳的页面运行。
- 修复核心日志批量追加时滚动超出当前列表项目数的问题。[GUI PR #30](https://github.com/sundaysebasidian-byte/weave-client/pull/30)

## 路由、轮盘与订阅

- 模式轮盘根据松手位置确认模式，处理多指、取消及与翻页手势的竞争。弹窗沿用应用的字号和阅读方向，右到左布局下的大字号列表横滑按顺序切换一档。窄屏也可使用可滚动列表，键盘支持方向键预览、Enter 确认与 Escape 关闭。
- 应用分流从总览进入。当前出口标为选中，返回总览时保留应用搜索和滚动位置，新规则须明确确认后才写入。订阅、策略组和本地策略各有入口，分流页可直接更换默认出口。
- 失效的应用规则只拒绝对应应用的流量。失效的默认出口提示重新选择。首次导入后，首页、节点和分流同步刷新，无须重开。
- 大节点列表在后台排名和筛选，切换来源会取消旧计算。测速重排期间保留可用列表。支持按协议筛选。批量刷新可以停止未完成的请求，已提交的刷新结果保留。
- 定时刷新只读取到期的订阅。预览和确认使用同一套数量变化校验，旧预览无法清除新预览。编辑策略组或分流时复用已校验的加密快照。

## 连接、存储与传输

- DNS、模式、预设和直连等设置按顺序在后台保存，连接等待已接受的模式变更写入。收藏和共享状态在保存成功后才更新界面。
- 闲置时按需绑定 VPN 控制服务。重复启动保留已有隧道，迟到的回调不会重新连接或清除新会话。失效连接停止轮询，滚动时暂停实时列表主动读取。
- 直连无需加载订阅，固定出口只加载指定来源。运行配置按需解密并复用索引，Clash 提供者直接读取已验证的节点对象。
- 加密备份直接写入有上限的暂存文件，输出格式兼容旧版。局域网接收按声明长度分配缓冲，限时读取并校验 UTF-8，关闭分享后收回监听与连接。凭据弹窗使用安全窗口。
- 图片二维码分块转亮度，减少大图的临时像素缓冲。更新界面在 Activity 重建时保留下载状态，由 Android 安装器确认安装。

## 性能实测

以下是所纳入改动的既有对照基准，涵盖特定工作负载。

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 800 节点 Clash 提供者载入中位数 | 16.9 ms | 2.9 ms |
| 800 节点 Clash 提供者线程分配 | 43.6 MiB | 8.3 MiB |
| Android 36 ARM64 模拟器闲置首页 PSS | 52.85 MiB | 47.01 MiB |
| 8 MiB 加密备份写文件线程分配，RC8 → RC9 | 49.86 MiB | 21.32 MiB |
| 4 MiB 局域网字段解码耗时，RC8 → RC9 | 1.59 ms | 0.91 ms |
| 4 MiB 局域网字段解码线程分配，RC8 → RC9 | 12.00 MiB | 4.01 MiB |

真机预测性返回、跨厂商设备表现及电池消耗待验证。各基准的环境、输入和采样次数见上方两份记录。
