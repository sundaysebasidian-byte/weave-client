# Weave Android 0.4.0-rc4 · Build 110

公开测试版：订阅更新先预览再确认，新手三步上手，迁移更方便。

![八种主题配色示意，非实机截图](https://raw.githubusercontent.com/sundaysebasidian-byte/weave-client/v0.4.0-rc4/docs/images/themes.png)

这是 0.4.0 的发布候选，以 **Prerelease** 公开，供愿意反馈问题的用户试用。它尚未达到稳定版验收范围；请先备份现有配置，不要把它当作唯一可用的客户端。

本次发布的是已冻结、已生产签名的 Build 110，没有重新构建或重新签名，也没有合入可选的到期时间溢出修复（见“已知问题”）。

## 本次更新

- **订阅更新先预览，再确认。** 更新订阅前会显示节点的增减变化，确认后才保存；点击取消，已保存的节点保持不变。
- **三步新手引导。** 导入订阅 → 选择节点 → 连接。可以跳过，也能在设置中重新打开；设置里另有“减弱引导动画”选项。
- **更多迁移途径。**
  - 通过系统文件授权，导入 CMFA 配置文档；
  - 通过官方备份文件，导入 Karing 订阅组，导入前可选择并预览。
  - 导入的是兼容节点的本地快照，不会迁移原订阅 URL、路由或 DNS 设置。我们不声称支持身份未经确认的 x2ray 客户端。
- **对话框更清楚。** 调整节点选择、局域网传输和二级设置对话框的层次、间距与操作反馈；补齐六种语言，并适配大字体场景。

## 从旧版本升级

升级前请先阅读：

- 公开的 Build 106 使用开发证书签名，本包使用生产证书签名，Android 通常**不能**用本包直接覆盖安装。本轮没有验收 106 的数据迁移。
- 迁移前，请在应用内导出加密备份，并确认它可以被解密恢复。
- 不要为了安装而卸载应用、清空数据或强制降级。
- 生产版 RC107–RC110 使用同一签名身份。

## 验证情况

**已完成**

- JVM 单元测试：356 项通过，0 失败。
- 隔离 Android 模拟器：231 项通过，4 项按条件跳过，0 失败。跳过项包括真实 TUN 流量与私有存储检查。
- Android lint：0 个错误，22 个警告。
- 以上是本候选先前的回归记录，不是发布当天重跑的完整测试。
- 2026-10-05，在安装了这个确切 APK 的 **Pixel 8 / API 37** 上完成四项有界 UI 检查：设置导航、外观选择器打开与取消、语言选择器打开与取消、单个订阅的更新预览与取消。预览会显示节点变化，取消后已保存节点数不变；外观和语言设置均未改动。

**尚未验收**

- 点击“确认”保存订阅更新；
- 同版本重装；
- 真实 VPN 端到端流量、泄漏与耐久测试；
- 各厂商 OEM 机型覆盖；
- Windows、macOS、iOS：仓库中有相应源码，不代表这些平台已经验收，也不属于本次发布。

应用内显示 VPN 服务在运行，不等于流量已经通过 VPN。

## 已知问题

- 极端超大、无效的到期秒数可能溢出，导致显示错误日期。常见的十位 Unix 秒数不受这一特定溢出影响。修复在一个独立的候选中，尚未合入 Build 110。
- 部分系统的“应用注册”检查是否接受此包尚未验证；生产签名不等于已通过系统注册验收。
