# Weave Android 0.4.0-rc4 · Build 110

订阅更新先看变化，导入和设置更清楚。

这是 **Prerelease 公开测试版**，适用于 **Android 8.0+、ARM64**。

## 本次改进

- **单订阅更新先预览。** 手动更新单个订阅时，查看节点增减后再确认保存；取消保留原节点。
- **三步开始使用。** 导入订阅 → 选择节点 → 连接。引导可跳过、可从设置重开，并提供减弱引导动画选项。
- **导入前可选择和预览。** 通过系统文件授权导入 CMFA 配置文档，或通过官方备份文件导入 Karing 订阅组。导入兼容节点的本地快照，不迁移原订阅 URL、路由或 DNS 设置；尚未确认 x2ray 客户端的迁移支持。
- **更清楚的操作反馈。** 整理节点选择、局域网传输和设置对话框，补齐六种语言与大字体场景。

## 验证范围

既往回归记录：**JVM 356 通过；隔离 Android 模拟器 231 通过、4 项条件跳过；均为 0 失败。** lint 为 0 错误、22 警告。这些不是发布当天重跑的完整测试，跳过项包括真实 TUN 流量和私有存储检查。

2026-10-05，确切生产 APK 在 **Pixel 8 / API 37** 上完成四项 UI 检查：设置导航、外观打开/取消、语言打开/取消、单订阅更新预览/取消。取消后已保存节点数不变，外观和语言值未更改。

**仍未验收：** 真机确认保存、同版本重装、VPN 端到端流量、泄漏与耐久、OEM 全覆盖及 Windows 10/11 VPN 回滚。显示 VPN 服务在运行不等于流量验证通过；其他平台源码也不代表该平台已验收。

## 已知问题

极端超大、无效的到期秒数可能溢出并显示错误日期，普通十位 Unix 秒数不受该特定溢出影响；独立修复候选尚未合入 Build 110。部分系统的应用注册检查仍未验证，生产签名不等于系统注册验收。
