# Weave Android 0.3.0-alpha77

让代理更好看，也更好用。

![八种主题配色示意，非实机截图](https://raw.githubusercontent.com/sundaysebasidian-byte/weave-client/v0.3.0-alpha77/docs/images/themes.png)

- **八种主题**：四种极简、四种艺术风，Liquid Glass 风格的通透层次；另有平整克制的素纸主题。
- **图形化分流**：为应用选择订阅、节点、直连或阻断，规则一目了然。
- **本地优先**：无需账号、不运营云端、不做遥测上报；订阅敏感信息在设备上加密保存。
- **持续维护**：计划长期维护、定期发布 GitHub 更新，由你决定何时手动升级。
- **网络与隐私检测**：一个入口查看出口 IP、延迟、探测失败率、常用网站连通性与浏览器隐私线索。
- **迁移与分享**：导入 CMFA、Clash、Karing 等客户端导出的兼容配置；实时扫码，并可选择分享哪些订阅。

本次公开预览汇总 alpha60 之后的 Android 改进，包含订阅解析、节点集合兼容、启动错误诊断及订阅详情滚动修复。仅发布 Android，不包含新的 macOS、Windows 或 iOS 安装包。

## 安装

在下方 Assets 下载与你设备架构匹配的 APK。大多数较新的 Android 手机选择 `arm64-v8a`；Android 8.0 及以上。

这是 **alpha 预发布**，安装包经过代码与资源压缩、不可调试，但仍使用既有本地开发签名，并非正式生产签名。相同签名的旧预览版可覆盖升级，建议先导出备份；如果提示签名不一致，请不要直接卸载或清空数据。

`SHA256SUMS.txt` 用于核对文件下载完整性。`CMFA-82b73a4-source.tar.gz` 和 `Mihomo-e26714a-source.tar.gz` 是锁定内核的上游源码归档；Weave 自身源码与补丁见本标签的 Source code / 仓库。复现说明见 [内核来源](https://github.com/sundaysebasidian-byte/weave-client/blob/v0.3.0-alpha77/docs/CORE_PROVENANCE.md)。

## 已知边界

- 真实订阅格式可能有差异；Walless 的完整节点数量恢复尚未用用户实样确认，不承诺兼容所有私有备份格式。
- HTTP 探测失败率不等于真实网络丢包率；网站可达不代表账号或流媒体已解锁；部分 DNS/WebRTC 结论需要独立验证。
- 无 Weave 云端不等于匿名或零风险。自选节点、订阅、DNS 与检测服务可能处理连接信息，详见 [隐私说明](https://github.com/sundaysebasidian-byte/weave-client/blob/v0.3.0-alpha77/PRIVACY.md)。
- 本轮没有连接真机，未新增真机或长时间稳定性验证。

遇到问题可在 Issues 提交设备、版本与脱敏错误码；请勿公开订阅令牌、密码、UUID 或完整日志。
