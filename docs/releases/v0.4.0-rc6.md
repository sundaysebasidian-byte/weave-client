# Weave Next 0.4.0 RC6 (Android) · Build 112

页面和模式都能滑动切换，动画更跟手，整体更省电更流畅。

这是 **Prerelease 公开测试版**，仅提供 **ARM64** 安装包，适用于 Android 8.0+。从 RC5 直接覆盖安装即可，签名与应用 ID 不变。

## 滑动与交互

- **底部四个页面可滑动切换。** 页面跟手移动，松手吸附到最近一页；底栏指示条跟随滑动，两页之间轻微拉伸。
- **首页模式胶囊可滑动切换。** 左右拖动实时预览全局 / 规则 / 直连，每过一档轻触一下，松手才生效。
- **分流页预设胶囊可滑动切换。**
- **返回键先回首页。** 在分流、订阅、设置页按返回会回到首页，而不是直接退出。

## 性能优化（10 项）

1. 编织线动画不再逐帧重组，1.7 秒连接动画期间界面更稳。
2. 编织线的路径、笔触和渐变按尺寸缓存，绘制时不再每帧分配对象。
3. 首页底部渐隐画刷改为缓存。
4. 翻页过程中暂停首页仪表盘轮询。
5. 跨多页点按底栏时不再加载中间页。
6. 分流页只在路由模式变化时刷新。
7. 状态提示只在文字变化时刷新。
8. 订阅页迁移候选列表缓存。
9. 订阅编辑弹窗的节点过滤和规则计数缓存。
10. 引导可用节点和外观调色板分组缓存。

## 问题修复

- 快速双击连接键会先连上又断开。
- 出口摘要有延迟时整行被染成强调色，现在只有延迟数字着色。
- 分流、订阅、设置三页标题高度不一致，切页时标题跳动。
- 首页滚动回调可能使用过期引用。
- 非首页按返回直接退出应用。
- 模式胶囊滑动未达阈值时没有任何反馈。

## 细节打磨（10 处）

1. 页面滑出时轻微缩放并淡出。
2. 底栏指示条在两页之间拉伸。
3. 底栏图标选中时弹跳上浮。
4. 页面吸附时轻触反馈。
5. 标题栏按钮按压回弹。
6. 连接与断开分别使用开、关两种触感。
7. 模式胶囊预览时着色并随手指倾斜。
8. 模式文字切换带滑动淡入。
9. 分组折叠箭头旋转动画。
10. 预设文字切换淡入淡出。

## 验证范围

JVM 单元测试、Android lint、Debug/Release 构建及隔离模拟器存储测试均已通过。本版只改界面与交互，不涉及网络、权限、存储、原生代码或订阅数据。**滑动手感尚待更多真机反馈**，VPN 行为与 RC5 相同。
