# Weave Next 0.4.0-rc8 · Build 114

这是 Android 未签名开发者预览。ARM64 APK 留待生产签名。签名、真机覆盖升级及实体设备功耗验收待完成。

本版包含 [PR #26](https://github.com/sundaysebasidian-byte/weave-client/pull/26) 和 [PR #27](https://github.com/sundaysebasidian-byte/weave-client/pull/27) 合入的 Android 改动。对应主分支的 [#26 CI](https://github.com/sundaysebasidian-byte/weave-client/actions/runs/45872889646) 与 [#27 CI](https://github.com/sundaysebasidian-byte/weave-client/actions/runs/45882123364) 均已通过。

## 本版改动

| 工作项 | 主要修改 |
| --- | --- |
| 轮盘触控 | 松手坐标决定实际模式。处理指针取消、多指和父级翻页争抢。 |
| 窄屏和 RTL | 轮盘物理坐标随文字方向镜像。空间不足时改用可滑动的选项列表，保留大字号。 |
| 轮盘绘制 | 缓存刻度和虚线画笔。拖动角度在绘制阶段读取，减少逐帧重组。 |
| 编辑分流 | 每次从总览打开。当前出口只展示为选中状态，返回键先退到总览。 |
| 策略选择 | 订阅、策略组和本地策略能独立访问。显示不可用订阅原因，切换订阅才加载对应测速信息。 |
| 新建规则 | 先选应用，再显式选择策略并写入。保存期间重新核对应用规则和出口引用。 |
| 默认出口 | 分流页可直接更换默认出口，主页显示直连模式和失效出口的区别。 |
| 入门引导 | 空订阅直接打开导入，失效出口直接打开选择器。引导只承认可用于运行的节点。 |
| 设置保存 | 模式、预设和国内直连按顺序落盘。连接等待已接受的模式写入，快速连续修改合并重载。 |
| 启动存储 | 主线程创建 ViewModel 前在后台读取设置快照，重复读盘合为一次。恢复状态更新也在后台执行。 |
| 闲置 VPN | 仅在发起连接或发现现有 VPN 时绑定控制服务。恢复前台时校对旧的连接状态。 |
| 已连接采样 | 首页与通知共享当前隧道版本的短时出口元数据，速度仍按采样读取。 |
| 应用选择 | 打开选择器才扫描应用列表，区分载入、失败与真实的空结果。 |
| 节点浏览 | 大列表在后台排名和筛选，输入搜索词时复用排序。两种节点选择界面可按协议筛选。 |
| 运行配置 | Clash 提供者直接提取已验证节点对象。固定出口和链式组按索引查找所需节点。 |
| 加密索引 | 生成配置复用订阅快照，并按需解密。启动修复复用同一个索引快照。 |
| 批量订阅 | 批量刷新只回读一次分流引用。编辑分流复用事务里的已验证节点和规则视图。 |
| 局域网传输 | 按声明长度分配缓冲区，限时接收。关闭界面或分享过期时收回监听和已接受的连接。 |
| 备份 | ZIP 输出直接进入加密流，保留已有备份格式和限制。 |
| 持久化与跨语言验证 | 收藏落盘成功后才更新界面。Android CI 单独保存应用分流和轮盘的测试收据，新增文字覆盖现有发布语言。 |

## 性能采样

- 800 节点合成 Clash 提供者，24 组配对测试。节点载入中位数从 16.9 ms 降到 2.9 ms，线程分配从 43.6 MiB 降到 8.3 MiB。该测试测量解析和节点对象投影。
- 同一 Android 36 ARM64 模拟器，优化构建的未连接首页，五次采样的应用合计 PSS 从约 52.9 MiB 降到 47.2 MiB。第二个进程变为按需启动。这是阶段构建结果。

测试范围包含运行配置、文件兼容性、应用分流选择、轮盘输入和 Android 生命周期。GitHub PR 与 Actions 提供对应代码版本的测试结果。生产签名、实体设备升级、电池消耗和跨厂商系统行为仍待验收。
