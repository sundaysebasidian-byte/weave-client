# Weave Next 0.4.0-rc9 · Build 115

Android ARM64 未签名开发者预览，基线为 RC8 合并提交 `ba53bd4`。生产签名、真机覆盖升级和实体设备功耗验收留待后续。

## 20 轮优化

| 轮次 | 改动 | 主要验收 |
| --- | --- | --- |
| 1 设置保存 | DNS、自动选点和网络选项按顺序在后台写入。自定义 DNS 地址和启用状态一起提交，失败时编辑框保留输入。 | 真实配置锁竞争、连续修改及表单失败重试。 |
| 2 VPN 启停 | 迟到的重载不会重连，重复启动保留现有 Android 隧道。 | 断开时发重载、重复启动、后台返回、发送真实 TUN 流量。 |
| 3 运行配置 | 有自动路由消费时才加载跨订阅候选。直连跳过全部订阅，固定出口只加载所需源。 | 运行配置计划和实际 Mihomo 验证矩阵。 |
| 4 策略组存储 | 校验并发布同一份加密订阅快照。只索引被引用的节点，返回值与落盘规范化一致。 | 策略组修改、恢复事务、冲突草稿和删除。 |
| 5 无效分流 | 仅拒绝失效应用规则的流量。无效默认出口继续要求重新选择。 | 验证 Mihomo 的 UID 拒绝规则和无效默认出口。 |
| 6 应用选择 | 从策略选择返回时保留应用搜索与滚动位置。用户明确确认后才写规则。 | 真实 Activity 输入、取消、返回和保存。 |
| 7 大节点列表 | 测速重新排名期间保留可用列表，切换源时立即隔离过期结果并取消旧计算。 | 6,000 节点界面测试和排序回归。 |
| 8 更新预览 | 旧预览不能清除新预览。需要二次确认的数量变化和禁止覆盖的审计结果用同一规则判断。 | 加密订阅回读、预览失效与确认事务。 |
| 9 定时刷新 | 设置和调度离开主线程。定时扫描只解密到期记录的来源。 | Android Keystore 跟踪，验证尚未到期的来源和全部节点索引均未解密。 |
| 10 批量刷新 | 允许停止未完成的请求，并保留已提交的收据和更新。 | 取消行为、加密提交竞争和界面反馈。 |
| 11 首次导入 | 首页、节点和分流读取同一更新后的本地配置。导入后无需重开。 | 从空库导入本地二维码内容并检查真实 ViewModel 的回执。 |
| 12 局域网共享 | 同一事务提交启用状态和凭据。关闭后清理界面持有的凭据，凭据弹窗使用安全窗口。 | 并发首次读取、禁用、再开启和凭据一致性。 |
| 13 实时连接 | 滚动时暂停主动读取，断开后清空旧连接并停止轮询，重连重新读取。 | 暂停、断开、重连和批量操作的 UI 回归。 |
| 14 更新安装 | Activity 重建保留同一个更新控制器和缓存 APK，用户仍通过 Android 安装确认。 | 真实 Activity 重建和既有下载、安装状态用例。 |
| 15 加密备份 | 加密数据直接写入有界暂存文件。只有加密成功后才打开用户选择的输出。 | 格式 v2 策略包恢复、篡改与损坏文件拒绝、分配量对照。 |
| 16 局域网文件 | 原始缓冲内验证 UTF-8 与边界，避免为每个字段复制大数组。 | 跨平台字节向量、截断与非法文本、加密局域网套接字。 |
| 17 首页采样 | 不可用路径不轮询。切换隧道版本时弃用旧采样和历史，保留已连接时的节流。 | 路径和修订切换、后台节流回归。 |
| 18 轮盘键盘 | Enter 打开或确认，方向键预览，Escape 关闭。沿用原有拖动和 RTL 交互。 | 模拟按键与原有触控回归。 |
| 19 图片二维码 | 分块转亮度，避免整幅 RGBA 像素数组，IO 和解码各走相应调度。 | 1536×1536 PNG、多语言内容及 Bitmap 释放。 |
| 20 VPN 控制连接 | 每次绑定拥有独立会话，过期回调无法清除新会话。控制连接无响应时停止使用旧的状态。 | Android 旧回调注入、真实隧道重绑及 TUN 请求。 |

## 性能采样

使用同一台 Mac 和 Temurin 17 对比 RC8 与 Build 115 的实际 Kotlin 实现。预热 5 次，逐次记录调用线程累计分配量与耗时。备份测量以 8 MiB 合成输入写文件，保留版本 2 加密格式，分别测 12 次。局域网测量使用 4 MiB 合成字段，对同一包解码并核对返回内容，分别测 24 次。

| 中位数 | RC8 | Build 115 |
| --- | ---: | ---: |
| 备份写文件的线程分配 | 49.86 MiB | 21.32 MiB |
| 备份写文件耗时 | 361.37 ms | 365.64 ms |
| 局域网字段解码的线程分配 | 12.00 MiB | 4.01 MiB |
| 局域网字段解码耗时 | 1.59 ms | 0.91 ms |

这些数字只覆盖对应基准。直连场景从加载全部订阅降到加载零个订阅。1536×1536 图片解码的临时整数像素缓冲从 9 MiB 变为 96 KiB，亮度和 Android Bitmap 缓冲另计。真机冷启动、升级、电池消耗及跨厂商系统行为待验收。

## CI

Android 流水线运行 JVM 测试、lint、调试和 R8 构建，并在隔离设备上核对 99 项存储恢复和 12 条功能回归的实际通过数。三条新增强制回归覆盖配置锁竞争、首次导入和大节点重排。ARM64 另外运行真实隧道、系统返回键、机型窗口布局、方向键、备份和局域网设备用例。
