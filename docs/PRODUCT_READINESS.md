## 验证记录

- 2026-10-29：Android `:app:testDebugUnitTest --tests io.weave.client.subscription.SubscriptionUsageTest` 通过，使用隔离 Gradle 目录、JDK 17、Android API 36；未启动 VPN。既有 UI Kotlin 警告不在本次边界修复范围。
- Mac 新增测试使用注入密钥与临时目录，不读写真实 Keychain；路由与导入测试使用离线夹具。实际核心回归验证自动/固定生成配置、随机本地监听/认证控制 API/PID 归属和停止清理；系统代理命令使用假实现，未修改用户网络。
- 实际核心测试另发现并修正既有 `MATCH,'group'` 错误：Mihomo 把规则内部引号视为组名字符；现在输出 `MATCH,group`，两种出口均由核心 `-t` 校验。
- Windows 核心测试在 macOS/.NET 10 上使用实际 Mihomo 和固定 geodata；本地 HTTP 上游验证请求认证与转发，Java 互传夹具覆盖 Android 互操作。Windows 专属 TUN 分支未在 macOS 执行，不把 runner 的通过数当作实机覆盖率。
