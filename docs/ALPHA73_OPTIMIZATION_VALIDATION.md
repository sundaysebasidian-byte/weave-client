| 原计划 | 本轮实现与保留能力 |
| --- | --- |
| 4 流畅度 | 首页滑动期间、检测/节点弹窗打开时暂停统计轮询；节点列表搜索/排序继续使用记忆化和稳定键；外观主题未重做。 |
| 5 内存与耗电 | 节点健康结果按订阅缓存，上限八份；下载和完整检测互斥；关闭检测页取消任务并保留完成的结果；连接失效清空出口结果；应用连接记录默认关闭，最多 64 条，不落盘。 |
| 6 启动 | 延迟创建订阅仓库，将索引修复/解密/读取移出主线程；一次读取生成订阅和节点列表；加载完成后才清理无效引用，导入等待初始读取结束；规则包也异步读取。没有承诺或测量一秒启动目标。 |
| 7 隐私检测 | 继续统一 IP、DNS 配置、IPv6、WebRTC 和浏览器身份入口；保留检测结果，手动刷新；系统保护区分已证实/未启用/未知。真实外部 DNS 泄漏仍需外部复核，未把本地配置包装成外部检测。 |
| 8 安全保护 | 继续使用已有 TUN/DNS/IPv6 拒绝规则与恢复机制；通过活跃 VpnService 的 Android 10+ API 按需读取 Always-on/lockdown，使用弱引用，检测页可进入系统设置。系统开关由用户手动设置；不新增模拟开关。 |
| 9 本地安全 | 收藏仅保存不透明订阅/节点 ID；诊断只在内存；连接记录不保存目的地址、正文或凭据，关闭清除；原加密存储和无遥测边界保留。 |
| 10 节点选择 | 当前订阅定位、搜索、收藏/收藏筛选、收藏优先排序、订阅测速缓存及检测时间；沿用固定节点出口和批量 HTTP 延迟/抖动/失败率检测；增加当前出口最多 1 MiB 下载样本。未增加所有节点逐一带宽测速，也不将检测时间称为最近成功时间。 |
| 11 分流 | 增加大陆直连/海外代理与全部代理预设；保留应用/域名/IP 编辑；路由解释先匹配与编译器共享的安全规则，纠正优先级与未知地域结果；增加按需系统应用归属观察。现有内核桥没有最终连接规则查询接口，因此应用连接记录不是最终规则命中日志。 |

## 选择性订阅分享

- 默认不勾选，支持全选/全不选、整行点按单选/多选。订阅刷新只移除失效选择，不自动扩大范围。
- 后端在读取订阅密文前校验选择：空选或失效 ID 拒绝导出，绝不回退为分享全部。
- 生成后列出实际分享清单，修改范围先使旧链接失效；旧服务任务仅能关闭自己持有的监听器。
- 真机已验证七个订阅勾选项默认全不选、全选/全不选、选一份/两份时计数正确；零选择时按钮父控件 enabled=false。
- 模拟订阅已通过选取、编码、加密、解密的往返测试，结果只含勾选项。
- 真实订阅二维码生成被自动安全检查拦截，未生成、下载或向其他设备发送私密订阅。真实局域网生成/撤销及双设备导入尚未实测；已询问用户是否允许临时生成后立即失效。
