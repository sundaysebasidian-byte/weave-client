# 本地备份与路由解释（开发中）

这组功能在开发构建 **0.3.0-alpha88** 中；尚未发布到 GitHub Release，也未安装到手机，不能据此判断手机上已安装的版本。

## Clash/Mihomo 配置边界

导入订阅时，Weave 会保留可执行的节点，并显示原文件中的代理组、规则、规则集数量。原代理组和远程规则集**不会**原样加载到 Weave 运行配置；其目标和优先级不能安全地自动映射到按应用分流。订阅详情可以显式导入一部分 `DIRECT`/`REJECT` 静态域名/IP 规则，最多 256 条；含代理组目标、`RULE-SET`、脚本或其他无法等价转换的规则不会导入。导入前应检查规则范围，导入后可在本地规则中逐条关闭或删除。

## 路由与 DNS 解释

分流解释器显示按当前设置推导的规则顺序与 DNS 策略，并标明无法离线判定的 GeoSite/实际内核命中。连接快照需要用户主动打开；自动出口变化只在连接页可见期间记录，且只标记“内核选择变化”，不推测是超时还是延迟触发。实际 DNS 响应、泄漏和网站可达性仍需主动检测，配置解释不能替代测量。

“稳定优先”自动选点延长探测间隔并提高延迟容忍度，减少短暂抖动导致的切换；这不保证某条线路始终可用，也不是全局网络故障自动修复。

## 离线加密备份

设置中的备份入口通过系统文件选择器导出/导入，不访问 Weave 云服务。备份包含订阅地址与节点凭据、应用分流、本地规则、策略包、DNS 与外观设置；文件使用随机盐的 PBKDF2-HMAC-SHA256 派生密钥，并由 AES-256-GCM 加密。密码至少 12 字符，丢失无法找回。导入先解密和显示条目数量，再由用户确认恢复；恢复后凭据重新用当前设备的 Android Keystore 加密。

备份文件可能被用户自行保存到云盘，Weave 无法控制用户选择的存储位置。不要把备份文件或密码发给他人。恢复在独立本地存储之间采用失败回滚；由于 Android 存储并非单个数据库事务，异常断电等极端情形不能承诺绝对原子性。跨设备恢复前先保留原设备和备份文件，确认订阅与分流无误后再删除旧数据。
