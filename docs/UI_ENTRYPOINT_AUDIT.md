# UI 入口审计

审计基线：Android `0.3.0-alpha44` / macOS `0.1.0-alpha06` / iOS `0.1.0-alpha01`。原则是只有已经接通状态、存储或系统页面的控件才显示点击反馈；
尚未实现的能力不放开入口、不显示箭头或开关。

| 页面 | 可操作入口 | 实际行为 | 验证 |
|---|---|---|---|
| 连接 | 连接 / 断开 | 请求系统 VPN 授权，启动或停止 CMFA/Mihomo 与 TUN；晚到的出站 socket 保护失败会保留前台服务并退避自动重建上一份健康运行时 | Android 16 模拟器、Pixel 8 / Android 17 |
| 连接 | 规则 / 全局 / 直连 | 持久化运行模式；连接中触发安全热重载 | 单测、模拟器运行 |
| 连接 | 当前出口 | 先选订阅，再从该订阅选择自动策略或核心名节点，也可直连 | 模拟器及 Pixel 8；固定 OpenVPN 出口已验证 |
| 连接 | 更多 | 跳转设置页 | UI 自动化 |
| 连接 | IP 质量检测 | 用户主动触发多端点 HTTPS 探测，显示当前出口 IP、ASN/地区/ISP、代理标签、边缘节点和 RTT；结果不持久化，检测页阻止截图 | 单测、lint、Android 构建；真机网络矩阵待补 |
| 分流 | 添加规则 | 枚举带启动器入口的应用并新建规则 | 模拟器及 Pixel 8 |
| 分流 | 应用规则行 | 先选订阅，再选择核心名节点、自动策略、直连或阻止 | 固定节点 UID 归属已验证 |
| 分流 | 删除规则 | 规则编辑弹窗底部删除，二次确认后清理持久化数据并回落默认出口 | Pixel 8 / Android 17 |
| 订阅 | 添加订阅 | 打开导入对话框 | UI 自动化 |
| 订阅 | HTTPS 导入 | 校验 URL、限制重定向/私网目标并加密保存 | 单测 |
| 订阅 | 扫描二维码 | 按需申请相机权限，使用系统相机预览并由 ZXing 本机识别 | 静态检查；真机待回归 |
| 订阅 | 识别图片 | 打开系统图片选择器，由随包 ZXing 本机识别 | 单测与 Android 构建；真机图片回归待补 |
| 订阅 | 选择文件 | 打开系统文件选择器，执行 5 MiB 与严格 UTF-8 校验 | 模拟器及 Pixel 8 |
| 订阅 | 订阅卡 | 查看/搜索节点，修改名称或 HTTPS 地址，以版本化加密 payload 原位替换并显示节点差异 | 单测、Android 构建；差异提示待 Pixel 8 |
| 订阅 | 检测节点 | 对当前运行配置中的订阅调用 CMFA provider 健康检查，显示真实延迟或超时；未加载时明确提示 | JNI 符号审计、单测、Android 构建 |
| 订阅 | 删除订阅 | 显示引用影响并二次确认；永久删除加密数据，引用规则回落默认出口 | 单测、Pixel 8 / Android 17 |
| 订阅 | 局域网互传 | 导出全部订阅为一次性二维码/链接；从链接或相机二维码导入 | 单测、Lint、Android 构建 |
| 设置 | Always-on 与断网保护 | 打开 Android 系统 VPN 设置 | 模拟器及 Pixel 8 |
| 设置 | 语言 | 选择简体中文、繁體中文、English、日本語、Français、Deutsch；立即更新稳定 UI 文案并持久化，用户输入保持原文 | 单测、Lint、Android 构建；六语言真机排版待回归 |
| 设置 | 自动节点策略 | 切换并持久化 `url-test` / `fallback` / 一致性哈希 `load-balance`，连接中安全热重载 | 单测、锁定 Mihomo 配置解析 |
| 设置 | IPv4 / IPv6 | 双栈或仅 IPv4；仅 IPv4 时关闭内核/DNS IPv6 并在 TUN 内拒绝 `::/0` | 单测、锁定 Mihomo 配置解析 |
| 设置 | DNS | 切换 DoH / DoT；所有配置拒绝应用明文 53、DoT/DoQ 853 和已知公共 DoH 旁路，过滤模式再加载本地广告/家庭规则，并在重载时清空 DNS/fake-IP 缓存 | 单测、锁定 Mihomo 配置解析 |
| 设置 | 阻止 UDP STUN | 在所有运行模式的应用规则前拒绝常见 STUN UDP 端口；界面提示通话兼容性影响 | 单测、锁定 Mihomo 配置解析 |
| 设置 | 国内智能直连 | 默认启用随包固定哈希的 lite GeoSite/GeoIP CN 规则，并为 CN direct 配置独立解析策略；应用分流保持更高优先级，可手动关闭 | 单测、Lint、锁定 Mihomo 配置解析 |

## macOS 入口

| 页面 | 可操作入口 | 实际行为 |
|---|---|---|
| 连接 | 订阅 → 节点 → 启动 | 按条件选择生成 Mihomo provider/自动组/精确节点组，启动 `127.0.0.1:7890` 本地代理 |
| 订阅 | 删除 | 从 Keychain 主密钥保护的加密订阅库永久删除 |
| 互传 | 生成二维码/链接 | 启动一次性局域网密文监听；可复制或立即失效 |
| 互传 | 链接/二维码图片导入 | 验证、解密、解析有效节点后原子写入本机加密库 |

macOS 未获得签名 Network Extension entitlement，因此“完整 VPN”和按应用分流只显示明确
能力边界，不提供可点击假入口。

## iOS 入口

| 页面 | 可操作入口 | 实际行为 | 验证 |
|---|---|---|---|
| 连接 | 订阅 → 自动/固定节点 | 生成隔离 provider 和版本化运行清单；只有 Packet Tunnel 与移动内核成功后系统才会报告已连接 | Swift 6 类型检查、共享核心自测；移动内核与真机待补 |
| 分流 | 添加/删除域名规则 | 域名后缀可选择不同订阅自动策略、固定节点、直连或阻止，按顺序编译在默认规则之前 | 共享核心自测 |
| 订阅 | HTTPS/文本/相机/照片/文件导入 | 限制协议、重定向、大小和 UTF-8；有效节点才写入 Keychain 主密钥保护的加密库 | 共享核心自测、Swift 类型检查 |
| 订阅 | 查看/搜索/选择/编辑/删除 | 显示原订阅节点核心名，修改或永久删除时同步协调默认出口与规则引用 | Swift 类型检查 |
| 设置 | DNS/IPv6/STUN/自动策略 | 持久化并写入内核配置；IPv4-only 同时停止安装系统 IPv6 默认路由 | 配置编译自测 |
| 设置 | 局域网导入/导出 | 使用与 Android/macOS 相同的单次、5 分钟 AES-GCM 链接协议 | 协议往返与篡改自测 |

iOS 普通个人 Packet Tunnel 不提供源 App 身份，因此没有按 App 选择节点入口。Per-App VPN
仅作为 MDM 管理版本能力记录。未嵌入 `WeaveMihomoMobile.xcframework` 时连接会明确失败，
而不是把只有 UI 或空 TUN 的状态显示为成功。

## 已移除或降级为状态展示

- 订阅卡片只在详情、节点列表与修改链路完整实现后恢复点击反馈和箭头。
- 局域网共享、高级路由和 Keystore 安全仍是当前配置说明，不显示开关或箭头。
- IPv4/IPv6、DNS、自动节点策略和 UDP STUN 已接通持久化、配置编译与安全热重载，因此
  alpha16 恢复真实选择器或开关。
- alpha17 的“检测节点”仅在 VPN 已连接时可用；未被默认出口或应用规则引用的订阅不会被
  偷偷加载，入口会说明如何启用，避免为了测速扩大运行时 provider 集合。
- 首页“更多”与“当前出口”原来的空操作已分别接到设置页和默认节点选择器。
- 设置 → 网络与安全 → 本地域名 / IP 规则：支持域名、后缀、关键词和 IPv4/IPv6 CIDR 的本机加密编辑、启停和删除；远程规则集仍不提供入口。
- 订阅页标题栏刷新按钮：仅刷新加密存储中的 HTTPS 远程订阅，逐项显示进度与失败数量。
- 版本号从 `BuildConfig.VERSION_NAME` 读取，不再使用静态占位文本。

## 兼容性边界

- 相机扫码使用系统相机预览，首次使用时按需申请 `CAMERA`；二维码内容由随 APK 分发的
  ZXing 解析器在本机识别，不依赖 Google Play services。
- 相册二维码同样使用随 APK 分发的 ZXing 解析器，并限制图片大小和解码边长。
- 订阅删除为明确标注的永久操作；当前不提供回收站，确认前会显示受影响规则与出口回退。
